01Python

SindhiScript سنڌي

A programming language written in Sindhi. It isn't a find-and-replace over Python: it has its own lexer, a hand-written recursive-descent parser and a tree-walking evaluator, and every keyword, operator and built-in is a Sindhi word.

  1. LexerIndentation, Sindhi digits, and it rejects invisible Unicode characters, so nobody can spoof an identifier
  2. ParserRecursive descent, straight to an AST, no parser generator
  3. EvaluatorWalks the tree with lexical scopes and closures
  4. REPL + web IDEAn interactive shell, and a browser editor built for right-to-left text
  • Functions, recursion and closures
  • Classes with constructors and inheritance
  • try / catch / finally, with error messages in Sindhi
  • Modules, imported from other .سن files
  • Lists, dictionaries, f-strings and Sindhi digits
  • A Python interop block, so any Python library is in reach

Sindhi Typing Master ٽائپ ماسٽر

A MonkeyType-style typing test for Sindhi. It pulls a random article from Sindhi Wikipedia, cleans it into sentences and times you on it, then shows your speed over time and a heatmap of the letters you keep missing.
